1. 幕4 要少“解释”，多“她”（最优先）
现在的问题不是写得不够狠，是写得太“懂”。侵害段落里叙述者还在做讲座：

“原初组织的造物主们为了他们心目中完美的‘爱’与‘顺从’，在底层基因里写死了极度敏感的生理反馈机制。到了第一国的训练营里，这段被保留下来的缺陷只被当作拿捏她们的刑具。”

这是全章最伤的一句。幕1 主管已经把那把锁的来历讲完了，读者不需要第二遍；而且这句话把读者从她的身体里推出来，推到讲台上。同类还有“没有任何感情基础，仅仅是物理按压，她的巴氏腺就开始不受控制地分泌黏液”——“巴氏腺”“分泌黏液”是施害者的解剖学视角，不是她的视角；它让这段同时读成情色和控诉，两种效果互相削弱。

改法：这一幕只保留三样东西——(a) 感官碎片，(b) 系统报错只留一处，(c) 她默背神经名称。第三样是全段最好的东西：“骶副交感神经。盆腔内脏神经。阴部神经。”那是她唯一还能做的事：退回到她背了五年的名词里。整段应该围绕这个写——用注意力的逃逸来写恐怖，比用生理细节狠得多。所有“为什么会这样”移到幕5、幕6。

2. 把“伪装”写成“自残”（最有价值的修改）
她压平兽耳、盘起尾巴、用鬓发盖住没有耳廓的侧脸。文中只写了一次“轻微的生理痉挛”、一次“平衡器官的突变让她的步态出现了瞬间的歪斜”，然后再没出现过。但这是她每天都要做的、会疼的、会流血的事：兽耳是她唯一的听觉器官，压平=半聋；尾巴是平衡器官，盘起来=走路发飘；侧脸没有耳廓=她永远不能侧过脸跟人说话。

每一次伪装都有代价，这本书就有了贯穿始终的肉身隐喻：要活在人中间，就得把自己折起来。 这比任何基因锁说明都有力。具体而不加字数：拉面店听不清老板说话只能看口型；麦当劳因为压着耳朵没听见赵旭走近；避难所摘下帽子的那一刻耳朵充血发麻，负四号递来一块热毛巾。

3. 让“可乐没测”成为伏笔
她拿出试纸测了牛奶，却直接喝了可乐。这是全章最好的“她自己没意识到已经中招”的证据，但文中没有点破。建议在幕5 让她自己想起来，只说一句：

“我测了牛奶。我没有测可乐。”

比任何忏悔都疼。

4. 赵旭需要一次“明知故犯”
他的设备、黑市渠道、挂单速度都说明他是专业的；一个专业的人不会在没上约束的情况下动一个军工个体。所以他必须有一次“我知道我不该，但我等太久了”的时刻。最好就放在他读出 94% 的那一刻，让他脑子里闪过三个字：

这次不卖。

人物立刻立住：他不是不知道风险，是决定为这个风险破例。“我给你一个家”也就有了双重含义——既是诱骗，也是他真的这么想。

5. 账本要有赌注
幕6 现在数字很准，但气氛平静：负四号不紧不慢地喝水、报账。建议给她一个“今晚为什么在算账”的理由——这个月短了，短的钱刚好是一个月的抑制剂（六千到八千）。这样那些数字就不是说明，是压力；十六号问“避难所的钱是从哪里来的”，也从好奇变成了“我还能不能留下”。

6. 三条规则不要排成清单
“第一、第二、第三”内容很好，形式太整齐，像安全手册。拆开：一条参观时顺口说，一条被她追问时反问，一条留到下一章。或者让十六号质疑其中一条（“那如果那个人真的只是想帮我呢？”），让负四号答不上来。教学场景有摩擦，才不像说明书。

7. 幕1 需要一个“人”
5.3k 字，主管全程独自内心独白。给他一次擦肩而过：一个技术员差点在走廊拐角撞见他，他得说一句什么。这一下能同时做到三件事——设施变成一个有人的地方、悬念起来、世界观从对话里出来而不是从脑内出来。现在开篇更像一份高质量的设定自述。

8. 结尾缺一个具体的钩子
“她翻到下一页”+灰频段很抒情，但读完不知道下一章要追什么。建议在灰频段那条黑市条目下面再加一行：追加悬赏，要求活体，署名 Z。或者让十六号在册子第七章的空白处写下四个词：拉面、薯条、可乐、馄饨。前者给情节，后者给人物，两个都给最好。

9. 两处可以删
幕3 问了两家旅店（200+摄像头、180只看证件）。第一家已经完成“贵+不安全+要露脸”的全部信息，第二家只是重复。
幕2 结尾和幕3 前半都在写“她在人类社会碰壁”，功能重叠。省下的篇幅给“被拒绝”那段——现在只有两个目标（公文包男人、便利店女孩），再加一个，“每个方向都被弹回来”的累才有重量。
10. 语言层三件小事
“不是A，是B” 是这章的签名句式。在负四号嘴里很好（“不是给你闻的，是给我保命的”），在叙述者嘴里太密，会变成作者在台前总结。
比喻要分人：她的比喻用军事/解剖（雷达、弹道），赵旭的用猎/钓（浮漂），负四号的用账/家务。现在“像一个钓鱼的人看见浮漂沉了一下”出现在赵旭视角是对的，但同类句子有时会滑到不该滑的人身上。
“兽耳娘”：赵旭用是对的（圈内黑话），负四号自称“兽耳娘避难所”有点怪。分清“他们怎么叫我们”和“我们怎么叫自己”，是免费的一层世界观。


设定与物理逻辑（读的时候真的卡住）
主管怎么把她搬出去？ 一个强制休眠的人，穿过三道防爆门、备用通道、围栏缺口。推演路线不等于能搬运，这是全章最大的一处空白。
外勤怎么敢靠近她？ 负四号自己说“我要是再在你床边多站两分钟，现在躺下的就是我”，可外勤是“闻到你应激过载漏出来的腺体味”找过去、把她背上车的。是戴了防护，还是等她昏过去、味道散了才靠近？
赵旭怎么知道她会去麦当劳？ 幕2 结尾给了灯牌，像他引导的，但他全程没跟她说过话。如果他只是跟踪，“他知道她会跟上来”就太巧了。
她为什么不换衣服？ 出逃时穿战术裤、战术靴，背包里明明有主管准备的换洗衣服。一身军品走进镇子，比耳朵更容易被认出来。
尾巴怎么藏？ 盘在腰上、掖进T恤，“从侧面看不出来”——盘一圈在腰上，正面应该很明显。
两个 94% 是同一个东西吗？ 拉面店那次是气味波形匹配，赵旭家里那次是芯片读取，文中两次都写“94%”，读者会以为是一回事。
【痛觉阈值：4.2】的单位是什么？ 这本书别处的数字都很硬（0.3秒、500元、480元、20元、200元），这个 4.2 像随手写的，反而破坏精确感。
负四号的耳朵被抑制了，尾巴为什么保留？ 是“部分删减”吗？还有，过渡间只写“把耳朵压好，衣服检查一遍”，没提尾巴——出门到底藏不藏尾巴？
第一国的追捕在哪里？ 红色通缉令发了，然后整章没有任何追捕动作。避难所敢把她放在四十公里外的市里，说明第一国的手伸不到那儿——为什么？这一句会决定整本书的紧张感。
“六分钟”的算术：快走五分钟、小跑四分钟，又说“留了六分钟，够他坐下来把气喘匀”。跑要四分钟，只剩两分钟。这是我读的时候唯一停下来算的地方。


麦当劳——“小镇半夜只有那一个去处”成立，赵旭不是预言，是守株待兔。但幕3 整整一段没有他，读者感受不到“被跟了一路”。 加一笔：她在便利店门口回头，看见街对面有个人低头看手机，她判断“不是跟踪”——因为他没有跟着她移动。让她判断错一次。 这一笔同时做了三件事：埋人、让“至少她没看出有人”变成伏笔、给她一个真正的学习点（跟踪者不需要移动）。

衣服——第97行明写了“证件、一点零用钱和换洗衣服”。如果确实没得换，删掉“和换洗衣服”五个字。 “军品也是时尚”成立，但赵旭现在的观察是“不像一个少女的衣服，哪怕是工装”——他看的是风格。建议把破绽改成状态：这套衣服没有一处是为自己改过的——裤脚没卷过、膝盖没磨出形、口袋里没有一张纸、拉链上没有挂饰。人穿衣服会留下私人痕迹，她的没有。这比“像军品”更高级，也不跟你的设定打架。

负四号——有一个词要换：十六号心里那句“被删减兽化性状的个体”，读者会立刻问“那尾巴呢”。改成“被删掉耳朵的那一批”，就跟背景板里“只抑制兽耳原基”对齐了。 还有：她阅历多，但她的“老”现在只体现在台词比十六号流利。让她老在具体的东西上——如何搞到抑制剂；知道哪家店可以赊；说“上一次搬家”时不说搬去了哪。

年龄——负四号可以直接从芯片读档，增加此处细节

时雨——既然是慌出来的，它现在写得太镇定了。第489行“叫我时雨就好。不是真名。”读起来像一个从容的假身份。 复用拉面店那个信号：她说完，后颈又凉了一截。同一个身体反应出现两次，读者自己会总结出规律——她每次说漏嘴，后颈先知道。

小说风险——既然是特意的，让它被说出口一次。现在“人气第二”和“压三年才准写”并排，容易被读成作者没想到。负四号一句就够：“我们知道这很危险。但我们需要钱，也需要有人记得。”

组织规模——“世界范围平级”很好，但第一章没有一处让读者感觉到外面还有。一处就够：过渡间那张地图，角落里几个用铅笔写的地名，擦过又写上。或者账本上有一栏“互助金：转出”，收款方是另一个城市。

搬运（第45–53行）——不写过程，写代价。三笔：他工装袖口有拖拽蹭上的灰；表在搬的时候磕裂了；他两天前把那段走廊的巡检记录改成了“设备故障”。每一笔都在写他是个什么人。

外勤（第865行）——两句。车上有一个第一国出身的同伴，纯血对那种抑制剂免疫，是他把她背下车的；负四号隔着两米、戴着香囊，等味道散了才靠近。这一改顺手给了你一个主题：救她的是同类，不是人类。还有——过渡间那两把钥匙，可以一把在第一国人手里，一把在第二国人手里，那扇门就从“互相威胁”变成了“同盟的形状”。

尾巴（第591行）——别写“从侧面看不出来”。改“从正面看不出来，前提是她不站起来”。她的藏法不是让尾巴消失，是用姿势换来的（坐、背靠墙、腿收上来）。她在麦当劳那个坐姿已经写对了，只需要让读者知道那是有意的。

两个94%（第245、499行）——给两个不同的指标名。气味那台读“相似度94%”，芯片那台只显示编码本身和“匹配”。读者就不会混，也更符合两台设备的功能差别。

痛觉阈值4.2（第650行）——删掉数字或给单位。这本书的精确感是攒出来的（0.3秒、480元、20元、94%），一个假数字会漏掉一片。只留【建议动作：顺从】反而更冷。直接删掉HUD式表达

六分钟（第11、53行）——跑四分钟、总共六分钟，喘气只剩两分钟。把“他给自己留了六分钟”改成“他给自己留了两分钟”。而且“两分钟把气喘匀”对一个中年文职刚好不够，这比“够他坐下来”更像他。

第一国追捕（全章缺席）——最需要你定的一条，它决定全书紧张感。三选一，写一句就行： (a) 不能公开：承认造了人形兵器等于承认违约，通缉令只走内部，外面看不到； (b) 不急：无源芯片不能定位，她只要不露脸就是一根针掉进海里，他们在等她犯错； (c) 够不着：那片林区紧邻军事管制区，他们也不敢大张旗鼓。 推荐 (a)+(b)：秘密，且被动。这两条同时解释了“她为什么能在市里住一个月”和“她为什么必须永远伪装”。

原初组织（第29行）——不解释他们，给他们留一个物件。比如源码最底下有一句题词，主管看了十年也没看懂；或者他抽屉里有一张不该留的照片。这是全书的道德地基（“为爱造物”），一个物件比一段设定有用得多，也给后面留了口子。
