## 幕2 RimFract

交完那个仓储系统的压测包之后，十六号脚底板上的最后一层暗红血痂也在第七天早上脱落了。新长出来的皮肤呈粉白色，用指腹碰一下还有微弱的刺麻感，但已经不需要再缠医用纱布。她把折叠轮椅用湿抹布擦了一遍，轮轴缝隙里的灰尘也拿旧牙刷刷干净，折好推回居住区卧室的墙角，换上了一双负四号找出来的厚底棉拖鞋。走路时，她的脚掌还是会下意识往外侧偏一点，避开脚心最嫩的新肉，步子有些慢，落地依然没有声音。

这天下午，工作室里只有负七号一个人在值班。三姐和负二号一早就开着旧面包车去城北建材市场转悠了，说是顺路看看便宜的二手隔音棉；负四号则钻进了走廊尽头那间飘着酸味的配药间，帮负九号清理二手小型离心机的转子。

十六号坐在靠窗的黑色ThinkPad笔记本前，屏幕上开着三个并排的终端窗口。前两天深夜改完那个并发死锁之后，她总觉得当时为了赶在十二点前交差写出来的二十四行代码还不够干净。那套代码是为了适配旧架构临时打的补丁，里头保留了两个多余的指针跳转和一次可以省掉的缓冲区拷贝。

趁着这两天手头没有急活儿，她新建了一个空白工程，把那套基于无锁环形队列和寄存器原子操作的内存调度逻辑单独抽出来，从头到尾重写了一遍。整个工具库没有业务层的包装，也不依赖第三方运行库，一共只有四个头文件和不到八百行纯C与内联汇编混写的代码。改完之后，她在本地开了四个虚拟机节点跑了一轮基准测试。老旧的笔记本风扇转了不到十秒，屏幕上就跳出了统计报表：在同等硬件开销下，这套轻量级工具库的并发吞吐量比目前市面上最流行的开源组件高出百分之三十八，尾延迟压低到了原来的四分之一。

“十六号，你又在跑什么压测啊？我这边的交换机指示灯闪得跟蹦迪似的。”负七号摘下一侧耳廓上的助听器揉了揉耳道，端着猫爪马克杯凑过来看了一眼。她的目光刚落到十六号屏幕右下角那张对比折线图上，揉耳朵的手指就顿住了。

“等一下，你拿来对比的那个基线，是现在境外大厂都在用的标准并发库吧？”负七号把助听器重新戴好，往前凑了半步，鼻尖几乎贴到液晶屏上，“你把人家的吞吐量超了快四成？内存占用还不到人家的三分之一？这八百行代码是你这两天自己敲出来的？”

“嗯，前天改完那个死锁，我觉得原来的内存分配方式太慢了，每次请求进来都要向系统内核申请一次堆空间，用完再释放，中间浪费了很多时钟周期。”十六号移动指点杆，把代码切到核心的内存对齐函数上，“我把内存块改成了固定步长的预分配环形槽，直接用处理器的缓存行对齐，数据从网卡进来之后不用经过二次拷贝就能算出结果。刚才我已经跑过边界溢出了，不会崩。”

负七号盯着那几百行排版工整的代码看了一分钟，忽然转身跑回自己的工位，拉抽屉翻出一本记满账号密码的线圈本，跑回来拍在十六号桌角：“把它传到开源代码托管平台上去！现在就传！”

十六号愣了一下，猫耳往旁边偏了偏：“传上去干什么？这只是我写着练手的，还没有结合具体业务做封装。”

“越是这种不带业务废话、纯靠数学和底层架构硬砸出来的轻量级工具库，在境外那些极客和量化团队眼里越值钱！”负七号说话难得这么快，脸颊泛起一点红晕，“咱们避难所平时在平台上接那种几千块钱的整站外包，之所以总被中间商压价，就是因为不能提供实名认证的公司资质，只能靠低价走量。可要是你手头有一个在开源社区拿了几百颗星的高性能底层库，那就不一样了！那些做高频交易、做分布式引擎或者搞底层算力优化的海外雇主，从来不管你现实里是谁，他们只认代码跑出来的硬指标！”

正说着，配药间的门开了，负四号一边摘着乳胶手套一边走了进来，身上带着淡淡的化学试剂气味。她把废手套丢进垃圾桶，走到桌边端起水杯喝了一口，随口问：“什么硬指标？老远就听见负七号在这儿嚷嚷。”

负七号赶紧把屏幕上的基准测试图指给她看，把刚才的话又说了一遍。负四号弯腰看了一会儿，直起腰把水杯放回桌上磕出一声轻响，手指插进口袋捻了两下运动裤抽绳，拍了板：“负七号说得对。咱们不能一辈子靠熬夜堆那种谁都能写的网页外包，单价低不说，还容易被卡脖子。十六号，你既然有这个底子，干脆趁现在直接在境外开源社区和那个免KYC的远程开发平台上注册一个独立开发者账号。把这套工具库作为你的开源代表作挂上去，以后你专门接底层优化、算法攻坚和漏洞悬赏的高单价活儿，跟工作室的大锅饭分开算。”

十六号仰起头看着负四号，手指在键盘边缘碰了一下：“分开算？那赚来的钱不进避难所的公账吗？”

“进公账有进公账的规矩，但账号必须是你自己的。”负四号把负七号那本线圈本翻到中间一页，指了指上面手写的一串境外网址，“在外面混，每个人都得有一张能在明面上行走的皮。我们没有人类政府的合法身份证，在网上，一个攒够了技术声望的独立开发者账号就是你最硬的通行证。哪怕将来哪天咱们这间避难所又得搬家，只要这个账号和手艺还在你手里，你去哪儿都能自己挣出饭钱来。”

她顿了顿，拉过旁边的椅子坐下，语气放缓了一些：“而且客户跟你沟通需求、签线上协议、往账户里打款，总得有个称呼。在咱们这两扇门里头，大家叫你十六号，这没问题；可到了外头的网络上，你总不能在开发者签名栏里填一串实验体编号吧？给自己起个名字吧，英文ID和中文署名都填一个，以后这就是你在外头吃饭的招牌了。”

负七号很快在旁边帮她配好了双层加密代理，把开源托管平台与远程开发平台的注册页面拉到了十六号的主屏幕上，笑着站起身：“我去给你倒杯热茶，你慢慢想，起名字可是件大事。”

脚步声走远了，负四号也转身去了阳台检查遮光帘的挂钩。电脑桌前安静下来，只有机身底部那把老风扇还在发出沙沙的轻响。十六号坐在椅子上，低头看着屏幕中央白底黑框的注册表单。表单的第一行是【Developer ID / 开发者唯一标识】，第二行是【Display Name / 署名与称呼】，一道黑色竖线光标停在输入框最左端，一明一暗地闪烁着。

过去十五年里，她从来没有遇到过起名字这道题。在培养仓里泡着的时候，她是立项书上的一行批次代码；进了地下训练营，她是靶场记分牌上的“16”，是实验日志里的“1BCP1N3-16”。直到七天前那个凌晨，在小镇十字路口那家亮着黄色灯牌的麦当劳里，有人端着托盘站在桌边，第一次问她叫什么名字。十六号看着闪烁的光标，右手食指在键帽上方悬停了两秒，落下去，在中文署名框里敲出了“时雨”两个字。

黑体字跳上屏幕的一瞬间，她头顶那对三花猫耳猛地往后贴紧了颅骨。鼻尖仿佛又涌来一股炸薯条油脂混着糖浆的热气，眼前闪过麦当劳落地窗上蜿蜒的水汽，闪过赵旭撕开番茄酱封口的手指，紧接着画面切进了那间飘着消毒水味的陌生客厅。廉价洗衣粉混着烟草的味道贴在脸侧，锁骨下方传来读取器冰冷的滴响，随后一只手死死攥住她从T恤下摆滑出的尾尖，顺着尾椎骨扯起一阵剧痛。

胃部深处抽紧了一下，涌上一股泛酸的寒意。十六号搭在掌托上的左手五指骤然收拢，指甲刮在塑料外壳上发出轻响。那个名字连着自己断掉的戒备、连着那罐失控的可乐，也连着那个差点把她重新关进笼子里的夜晚。她右手小指重重按在退格键上，连按两下，将屏幕上的“时雨”两个字删得干干净净，输入框重新变回一片雪白。

十六号松开紧绷的指关节，慢慢靠回椅背上，低头深吸了一口气。胸口那只浅蓝色的布袋香囊贴着下巴，晒干的草叶散发出干燥的气息。阳台上，负四号正踩着小板凳把遮光帘挂钩往里扣，灰狼尾巴在半空中晃来晃去；厨房那边传来负七号冲热水的哗啦声。这里是避难所，过渡间外面锁着需要两把钥匙才能同时打开的防盗门，再也没有人能捏住她的尾巴把她往卧室里拖了。

她闭上眼睛，脑海里杂乱的噪点一点点沉淀下去。黑暗中，最先浮上来的是咬破铁丝网逃出来的那天傍晚，她从地下设施外头醒来时迎面吹过来的第一口林间晚风。那口风带着夜露和草木的气息，她仰起头，透过层层叠叠的树冠缝隙，看见高空的气流正把漫天流动的晚霞撕成细长的条带，黄橙色与红紫色在视野里铺开。紧接着，画面滑到了她从赵旭家挣脱、赤着流血的脚逃进镇西树林的那天深夜。就在她顺着湿滑的苔藓倒在林间空地前的一刻，头顶浓密的枝叶被夜风吹开一道口子，月光从树梢漏下来，折在林间那道溪水边缘，碎成一圈一圈透亮的微光。

十六号睁开眼睛，浅褐色的瞳孔里映着屏幕上闪烁的光标。她重新把双手放回键盘上，指腹贴着微温的键帽，十指敲了下去。第一行英文ID的方框里跳出了`RimFract`八个字母，紧接着她按下切换键，在下一行的中文署名栏里敲下了`林澈`两个字。

敲完最后一个字符，她移动鼠标点下发送验证码的按钮。左手边的按键旧手机屏幕亮起，收件箱里跳出一条六位数字的短信。她把数字填进去，勾选底部的开源协议，按下了回车键。页面刷新后，她新建了一个公开代码仓库，将那八百行无锁内存与并发优化工具库连同测试脚本一起推了上去，只在说明文档里留了三行参数指标，便关掉了上传窗口。

负七号端着热茶走过来的时候，正好看见屏幕右上角挂着的那个新名字。“林澈，RimFract……”她把茶杯放到桌上，轻声念了一遍，眼睛亮晶晶地笑了起来，“这个名字真好听，听着就像山里干净的溪水一样。以后外头那些客户找你，我就让他们管你叫林澈啦？”

十六号捧起温热的茶杯喝了一口，茶叶微苦的清香在舌尖散开。她摇了摇头，头顶的三花猫耳抖了抖，看了一眼从阳台走回来的负四号，又看了一眼負七号，小声说：“那是填在表上给外面的人看的，客户签协议和打款需要一个名字，我就填了那个。可是在这两扇门里头，你们还是叫我十六号吧，听着你们叫十六号，我才觉得自己是在家里。”

负四号闻言脚步顿了一下，灰狼尾巴在身后轻轻扫了扫裤腿，嘴角弯起一抹笑意：“行，名字就像是出门穿的外套，外头叫林澈，家里叫十六号，咱们自己人分得清清楚楚。”

那个连项目介绍都只有三行的轻量级工具库，在上传后的第三十六个小时，被一个常年维护开源高性能网络引擎的海外开发者翻了出来。对方把代码拉下来跑了一遍本地压测，当晚就在境外系统编程论坛上发了一篇拆解长帖。帖子在两天内被顶上了论坛周榜前列，不少做底层架构和高频量化的程序员顺着链接涌进了`RimFract`的主页，仓库星标数一路涨到了几百颗，提交区里塞满了远程合作邀请。十六号穿着宽松的旧卫衣坐在转椅上，一边晃着尾巴喝热茶，一边听负七号念那些英文留言，偶尔抬起头问一句：“发留言的这些人里，哪一家给结现钱最快？”
