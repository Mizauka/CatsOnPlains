### 关键场景

**名字（幕2）**

- 她先写“时雨”，删掉；光标停住；想起麦当劳窗上的水汽、林子里的风、溪水边的碎光；敲下“林澈 / RimFract”。
- **正文不解释词源**。Rin / Rim / Fract / refraction 的链条只作为作者向笔记；以后可以让负四号或女医生好奇问起，她轻描淡写说一半。
- 对外：林澈、RimFract；对内：十六号；“时雨”是那一夜的污点，废弃。
- 名字不是本章高潮，是插曲；她需要名字首先是因为平台要填表、客户要称呼、工资要打款。

**八千块（幕4）**

- 到账八千；她想全交；负四号逼她留四千；账上短四千。
- 负四号偷偷把自己的抑制剂剂量减半；十六号在药盒里发现；负四号只说“这个月的窟窿我来补，你留着你那四千”。
- 十六号用两千换成避难所的米、油、药；负四号骂了她一句，没让她退回去。
- 这是她第一次持有完全属于自己的钱，也是她第一次用钱选择“留下来”。

**自己的可乐（幕5）**

- 她用自己赚的钱买一罐可乐；甜，但没有命令、没有伪善、没有被迫的拥抱。
- 她用行动验证负四号那句“可乐本身是好的”。
- 小东西：坐垫、杯套、床铺上的第一件“自己的东西”。

**女医生与玄关（幕7–10）**

- 医生：阳光、爱笑、逛精品店、买小零食；人类都市女性语体；医学上极敏锐。
- 玄关：医生一句“去我家”触发赵旭“我家有个空房间、流浪小猫算你运气好”的记忆；十六号退到走廊死角，手扣刀榫。
- 医生的反应：不恼怒、不拉扯；退开两米；把门拉到最大、门吸固定；“门永远开着，随时可以走”。
- 喝茶；十六号问“你能弄到抑制剂吗”，医生摇头：“那东西不在医院的药品目录里。我能帮的只有外伤和手术。”
- 触诊前医生问“我可以碰一下吗”；十六号点头才伸手；碰之前说“会有点凉”。
- 芯片紧贴锁骨下静脉筋膜；医生借用无菌手术室切除；避难所配药间没有无菌条件，不敢动刀。
- 聚餐：她第一次坐进这群人的正中央；她确认自己想守护这里的生活。

### 关键场景

**断嗅（幕5）**

- 高浓度竞争性抑制剂**对人类没有作用**；它只让猎食者手里的化学气味分子读取器爆表、失去方向。
- 她把香囊塞进第二国外勤怀里；把气味往相反方向的通风口引；两个猎食者追错方向，剩下的人犹豫两秒。
- 她利用这两秒切进死角，短刀挑手腕肌腱、膝窝韧带，把外勤从捕网下拖出来。
- 短刀砍在防暴叉钢杆上崩出缺口；小臂被电击器擦过，留下焦麻感；她第一次清楚知道“下一次需要枪”。
- 撤离前从读取器里拔出存储卡，日志最后两行：
  - `P1N3-16：人类受体无响应。`
  - `P1N4-?：人类受体阳性。编号缺失。`
- 这是中立国线的远期伏笔：P1N4 批次里有一个对人类也有效的个体，编号缺失；猎人手里只是半张军方泄露的资料，中立国手里可能有更完整的那半张。

**识破诱饵（幕6）**

- 黑市的“新兽耳娘词条”是针对避难所“见同类就救”的习惯抛出的鱼钩；即便真有其人，也已被当成钓面包车的饵。
- 她判断不能回原公寓，先去兄弟避难所接线点；受伤的老外勤从“这丫头”变成“服了”。

**权能移交（幕7）**

- 负四号确认公寓被同一批黑市联合清剿网摸排，正在销毁硬盘、放弃两套出租屋、执行断尾搬迁。
- 分工不是加冕：十六号管外勤路线、据点防卫、现场决断；负四号管账本、药源、避难所网络、对外谈判。
- 负四号把路线图和车钥匙推给她，自己留下账本：“路线你定，账我来算。”十六号说“我不懂账”，负四号说“你懂怎么让我们活”。

## 五、第3–5章（宏观）

### 第3章：转（上）——三次会议与接枪（8–9幕，约4.5万）

**新据点**：断尾搬迁后的第三天，废墟还没收拾完；黑市广播里出现针对新据点城区的排查令；两名外勤伤还没好；药价还在涨；搬家的老办法用完了。

**三次闭门会议**：

1. **新据点里的警报（“搬完了，然后呢”）**
   - 负四号与老成员的第一反应：再往南撤一次，把剩下的钱烧完。
   - 十六号：再撤就是走进黑市布好的口袋；对方要的不是地址，是“一被摸到就搬”的模式；她们是特种资产，被抓就是脑控切除、活体取药、暗网心电图。
   - 决议：放弃继续逃，正式接触南方武装避难所，谈一批抹掉编号的自卫武器。

2. **废墟里的经济账（“军火贸易与生存倒挂”）**
   - 外包中断、抑制剂暴涨，写代码和写网文填不上每月近万的药费窟窿。
   - 第二国同伴怕武装引来军警封死药路；第一国外勤早就憋着火。
   - 负四号摊开兄弟避难所的加密账册：南方几个避难所靠地下军火改装与转运维持药费；愿意按配额拨一批抹号自卫武器（包括 Steyr M9-A1）。
   - 决议：接纳配额；由唯一受过五年正规军用特攻训练的十六号负责战术重组。

3. **进攻性防卫确立（“把防线推到门外”）**
   - 十六号的三步破局：
     1. **以打促防**：挑一个跳得最高、手握赵旭悬赏线的狂热者中介据点，夜间精准拔点；不恋战，打断骨头、打废设备，让黑市知道“盯这群兽耳娘的伤亡成本高于悬赏金”。
     2. **武装护送**：掩护掌握“第四代抑制剂低成本合成工艺”和原初数据的脱逃研究员转移，解决药源。

## 七、写作守则（去AI感）

1. **严控破折号解释句**。不要写“她看了一眼邮筒——训练手册教过，邮筒能挡9毫米弹”。写动作：“她走过街角，目光在铸铁邮筒和水泥花坛的厚度上扫了一遍，脚步往掩体死角偏了半步，右手插进挎包暗层。”读者自己会读出来。
2. **每幕只留一个核心硬核词，其余化为生活错位感**。做饭不要堆化学名词；写她拿量杯量生抽、端平到视线高度看液面。训练底子从动作里漏出来，不从名词里漏出来。
3. **四套语体严格隔离**：

| 人物 | 语体 | 标志动作 |
| --- | --- | --- |
| 十六号 | 短句、感官先行、对善意慢半拍 | 耳朵转向声源、尾巴在安心的人身边轻扫 |
| 负四号 | 接地气、算账逻辑、冷面心软 | 捻运动裤抽绳、杯底磕桌、先做小动作再说话 |
| 女医生 | 明快、温和、有分寸、医学上极精准 | 退两米、门吸固定、问“我可以碰一下吗” |
| 老外勤大姐 | 爽利、粗粝、江湖气、护短 | “你在家歇着，这点小活姐几个去就行”；受伤后骂骂咧咧地服软 |

4. **战斗写生理机制，不写数据报告**。不要写“肾上腺素飙升30%”。写手电强光、防暴叉刮墙的火星、她咬破舌尖、读取器爆表、短刀崩口、电击器擦过小臂的焦麻。让“需要枪”从缺口里长出来。
5. **名字不解释词源**。正文只写光标、退格、林子里的风、溪水边的碎光；Rin/Rim/Fract/refraction 的链条留给作者笔记，以后让负四号或女医生问起，她只说一半。
6. **知识差要守住**。十六号不知道“原初”；负四号知道；主管知道；赵旭只知道黑市层级；避难所档案写“原始编码”，不写“原初组织”。十六号第一次听见“原初”时，只把它记下来，不追问。
7. **术语要分清**。纯血 = 原初完整副本；第一国 = 准纯血/培育体；腺体 = 第一国加装；抑制剂 = 药店/医院没有，只能黑市/DIY。
8. **权能移交不是加冕**。十六号管路线、防卫、现场决断；负四号管账本、药源、网络、谈判。两个人互相需要，不是一个人登基。
9. **consent 要写两层**。宏观是“门永远开着，随时可以走”；微观是“我可以碰一下吗”“会有点凉”。两层都有，才算把“尊重”写完整。
10. **温馨场景下面要有一点不安**。药价、房租、楼下生面孔、平台陌生私信、医生家没锁的门。读者在替她攒安全感；攒得越多，后面失去时越疼。
