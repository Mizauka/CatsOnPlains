1. 幕6（账本）的“去说明书化”与戏剧化提炼

现状：负四号推着轮椅，依次走过“过渡间→工作室电脑→排版小说→档案架→厨房→药品室→上下铺卧室→算账”，信息量极其密集，但行动线偏向被动接受。
建议：
删减合并过渡段：正如你在编排说明中所计划的，将厨房、药品室、上下铺卧室的停驻彻底删去，改为推行过程中的一笔带过（如“推过走廊时，旁边半掩的房门里传出上夜班同伴压抑的鼾声，空气里飘过一丝被抽油烟机洗过很多遍的饭菜香”）。
让账本与具体物件绑定：不要让负四号单纯报菜名式地念数字。可以让负四号从抽屉里翻出一盒快见底的廉价药膏，或者指着门后一张用胶带贴满修改痕迹的应急撤离地图：“上次连夜搬家，两万块备用金三天烧完。我们能活着，是因为每张发票后面都压着命。”
将字数压到 5.5k–6.0k 左右，六幕的节奏会变得极为紧凑精炼。
2. 幕4受侵害时的叙事视角（POV）微调：让“哲思”退后，让“感官与代码”上前
现状：在十六号被侵犯时，正文有一段极其深刻的议论：

“每一种抽搐都让她更清楚地认识到：不是赵旭在侵犯她。是造物主在通过赵旭侵犯她。他们的手指从她出生的那一刻就已经放在这个按钮上了。赵旭只是恰好路过……”

建议： 这段剖析极具文学深度，但放在十六号被生理折磨、神智即将崩溃的千钧一发之际，显得略微过于理性与全知。 建议将这种成熟的形而上议论，转化为十六号脑中冰冷崩溃的生理词条闪回（例如神经反射代码的报错、痛觉阈值的红字警告）；而将“不是赵旭，是造物主在通过赵旭侵犯我们”这层深刻的认知，放到幕5或幕6她与负四号复盘“分不清哪个是可乐，哪个是设定”时由负四号点出，或由十六号在抚摸脚底伤口时在沉默中领悟。
3. 增强赵旭在幕4开头的“伪装耐心”
现状：赵旭在麦当劳表现得极为克制、擅长心理战，但一进家门给完可乐、等十六号洗完澡出来，几乎立刻就撕破脸皮动手捏尾巴、扯帽子。
建议： 赵旭可以表现得更狡黠、更像一个善于温水煮青蛙的猎人。例如：
他故意拿出一份看似正常的热牛奶或面包，言语间不断用“封闭学校很苦吧”、“我认识做假证的朋友，明天带你去补办”来继续麻痹她；
直到他裤兜里的读写器“滴”的一声轻响，读取到了那串价值连城的军规代码 1BCP1N3-16，确认了这是万中无一的“纯血特攻资产”，他眼底的贪婪与病态才彻底压制不住。这种从“精心伪装的善意”到“贪婪暴走”的阶梯式推进，会让恐怖感更加窒息。
4. 语言习惯的进一步提纯
全书文笔冷峻、刀锋般锋利，但在部分描写中仍有一些句式习惯可以进一步洗练：
克制“不是……而是……”排比：虽然比v4版减少了许多，但在全篇中依然能看到类似“不是A，是B”的判定式句式。偶一用之能增强手术刀般的精准感，用多了容易产生作者在台前强行总结的说教感。可以直接用动作与生理反应说话。
强化市井冷暖的反差细节：拉面店的那碗豚骨面、麦当劳那包带盐粒的薯条、避难所那碗浮着葱花的猪肉大葱馄饨——这些具有烟火气的食物描写极其成功，是整部灰暗小说中照亮十六号人性觉醒的锚点，后续章节可继续保持这种“冰冷生化代号 vs 市井温热碳水”的审美张力。


在反复推敲文本动线与生理逻辑后，以下几处存在一定的内在张力或未解释清楚的疑问：

1. 赵旭的定位自洽性：他是“自留的狂热恋物癖”，还是“专业的赏金猎人”？
疑惑点：
在麦当劳和家里，赵旭表现得像一个极具心理操纵技巧的恋物癖，他渴望的是把十六号“圈养为独占的金丝雀”（“我会给你一个家，没人能找到你”、“关起来，锁在这里”）。
但另一方面，他随身揣着高精度的气味/费洛蒙比对仪、能在身体接触瞬间近场读取锁骨RFID芯片，且在被咬断手臂筋膜、十六号逃跑的第一时间，他熟练地把“出厂芯片编码、假证编号、逃亡方向”挂到黑市变现。
追问：如果赵旭是一个以卖货变现为目的的职业猎人，猎人在没有完全通过药物或物理拘束彻底废掉一个高危军用个体之前，绝不敢毫无防备地解开裤带进行肉体猥亵；如果他是一个单纯的病态恋物癖，他这套专业仪器与黑市挂单渠道又显得过于“职业化”。他在黑市生态链中到底属于哪一环？

解答：这里赵是“自留的狂热恋物癖”，为了达成目的成为过“专业的赏金猎人”，这个会在后续剧情准备。

2. 十六号的战斗素养与反杀脱逃时的“慌乱落差”
疑惑点：
幕1确立了十六号是“军工级特攻杰作”、“能在肌肉纤维撕裂前接管控制权”、“0.3秒完成弹道解析”、“精通近身格斗与致死手段”。
幕4中，当肾上腺素暴冲解开基因锁、她成功用头槌砸碎赵旭鼻骨、咬穿其手臂骨膜筋膜、顶中肝脏使其惨叫倒地后，赵旭在生理上已经彻底失去行动能力。但十六号在冲出大门时，却慌乱到连近在咫尺的背包（内含假证和480元救命钱）和浴室门口的靴子都来不及拿，赤脚踩着碎玻璃狂奔三公里。
追问：对于一个经历过五年严苛战术行军训练的特工而言，在敌人倒地哀嚎的数秒内顺手抄起装备是刻在骨髓里的本能。如果她此时是因为遭受侵害后的心理幼态崩溃/解离（Dissociation）而导致战术素养全面崩塌，正文需要更明确地强调“这一刻战术程序被尖叫的恐惧彻底吞没了”，否则读者会疑惑：为什么一个能瞬间咬断骨膜的特工，在占据绝对上风后会落魄得像一个毫无防抗经验的小女孩？

解答：增加强调“这一刻战术程序被尖叫的恐惧彻底吞没了”，增加心理幼态崩溃解离描写，并且重点放大她虽然被专业训练了这么久但实际上还是孩子心智的特点

3. 外勤营救在时空窗口上的“巧合度”
疑惑点：
幕6指出，避难所位于直线距离四十公里外的市区。
案发时间在凌晨一点以后：十六号逃入树林→神经反噬干呕→看着刺猬发呆爬起。从赵旭负伤挂单到黑市，再到避难所截获情报、派出车辆、在黑夜中行驶40公里赶到镇西林区边缘、顺着血迹在树林里找到她，整个过程至多也就一两个小时。
追问：避难所的外勤是怎么赶在本地黑市买家之前抵达的？是避难所恰好有外勤在小镇附近夜班/巡查，还是避难所在该卫星镇本身就有前哨流动点？需要补上一两笔，避免给读者留下“远在四十公里外的同伴机械降神”的印象。

解答：需要为营救加上有流动的巡查员的细节

4. “侧面完全无人类耳廓”的生理外观在市井中的暴露风险
疑惑点：
纯血个体的耳部解剖学非常独特：头顶兽耳，侧脸至鬓角下方是平滑的颅骨，没有人类耳道与耳廓。
十六号用软边帽压住兽耳，用鬓发遮盖侧脸。但她在拉面店低头喝光最后一口汤、在麦当劳卡座把脸埋在背包上、在冷风中走动时，风和动作极易掀开鬓发。
对于任何一个人类而言，看到一个年轻少女侧脸光秃秃、没有耳朵，在视觉上是极其惊悚的“畸形/怪物”感（甚至比看到动漫风的发箍更扎眼）。拉面店老板只把她当成“封闭式学校的学生”，赵旭也只是靠计数器和三花毛辨认。十六号是否在出门前有过针对侧脸伪装的特殊处理（如医用胶带固定鬓发）？

解答：增加描写头发厚密发亮足够，并弱化“侧面完全无人类耳廓”的描写，把这一部分移到第一幕主管放走时的部分
