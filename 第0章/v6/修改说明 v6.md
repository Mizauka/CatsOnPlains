# 第0章 v6 修改说明（证件类型明确为护照）

v6 基于 v5，v5 保留。只明确证件类型，并加两处“她记得护照信息页”的伏笔；赵、避难所、旅店、其他泛指“证件”的地方一律未动。

## 改了什么

1. **幕1 证件类型**：原“一张无法通过校验的伪造芯片证件”改为“还有一本护照。芯片是真的，本子是假的，照片是打印上去的。护照国选的是同语言、免签、不会配合第一国核查的那种；入境记录走黑市渠道，不用买通谁。”
2. **幕1 背信息页**：她翻开护照，把姓名、性别、出生日期、护照号、签发国、有效期、最下面两行机器码，一个字一个字背了三遍，再放回夹层。
3. **幕6 想起还记得**：写完“拉面。薯条。可乐。馄饨。”之后，她忽然想起那本护照，信息页上的每一项还记得，一个字都没忘。她不知道自己为什么还记得，把这件事放下了。到此为止，没有说有什么用。
4. **灰频段**：清单上的“假身份编号”改为“护照号”；“他认识那个编号。那个假身份是他做的——一张过不了校验、连旅馆前台都骗不了的证件”改为“他认识那串号码。那本护照是他做的——芯片是真的，本子是假的，照片是她的”；“把证件从一只背包里翻出来”改为“把护照从一只背包里翻出来”。

## 没动什么

- 赵旭问“身份证带了吗？没有的话明天带你去补办”——不动。他不知道她的假身份是护照；就算她真有身份证，他也未必分得清真假。
- 避难所“证件的事我们记下了。这里的规矩是，证件一旦离身，就作废”——不动。护照已经在赵手里，要不回来。
- 幕3 旅店、幕2/3/4/5 里那些泛指“证件”的地方——不动，保持留白。
- 护照国不点名，只写“同语言、免签、不会配合第一国核查”；入境记录只写“走黑市渠道”，不写具体门路。
- 护照不在她手上，也没有图片，所以幕6 的记忆不承诺任何用途，只停在她还记得。
